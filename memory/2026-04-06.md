## SSH 连接修复记录
- 问题：root 的 authorized_keys 为空 + 密码登录被关闭 → SSH 被拒
- 修复：重新生成密钥 + 开启密码登录 + 设 root 密码
- 坑：Windows 记事本会给 SSH 密钥加 CRLF 换行符 → `invalid format`
- 坑：`icacls` 给 `(R)` 权限太死，写不回去
- 最终方案：在 Drizz 本地用 `ssh-keygen` 生成密钥对，把公钥贴给我装到服务器 → 100% 格式正确
