# 睡前 AI 故事续写机 (MVP) 开发计划

## 1. 阶段一：基础设施搭建 (Day 1)
- [ ] **前端环境配置 (Client)**
    - [ ] 安装 Tailwind CSS 并初始化配置。
    - [ ] 安装核心依赖：`lucide-react` (图标), `framer-motion` (动画), `clsx`, `tailwind-merge`。
    - [ ] 清理默认模板代码，建立基础页面结构。
- [ ] **后端环境配置 (Server)**
    - [ ] 安装核心依赖：`express`, `ws` (WebSocket), `cors`, `dotenv`。
    - [ ] 安装开发依赖：`nodemon`, `concurrently` (用于同时启动前后端)。
    - [ ] 创建基础的 Express + WebSocket 服务器结构。
- [ ] **本地 HTTPS 配置**
    - [ ] 使用 `mkcert` 生成本地 SSL 证书。
    - [ ] 配置 Vite 和 Express 支持 HTTPS (为手机端调试麦克风做准备)。

## 2. 阶段二：核心链路打通 (Day 2-3)
- [ ] **后端 AI 服务集成**
    - [ ] **LLM 服务**：集成 OpenAI 兼容接口 (DeepSeek/OpenAI)，实现流式 (Stream) 文本输出。
    - [ ] **TTS 服务**：集成 `edge-tts` (或 Azure TTS)，实现文本转音频流。
    - [ ] **业务逻辑**：实现 `语音转文字 (STT)` -> `LLM 生成` -> `TTS 合成` 的处理链路。
- [ ] **前端音频处理**
    - [ ] **录音功能**：使用 `MediaRecorder` API 实现录音并转换为 Blob。
    - [ ] **WebSocket 通信**：实现前端与后端的实时消息收发 (发送录音，接收音频流)。
    - [ ] **音频播放**：实现基础的音频播放器，支持播放从后端接收到的音频片段。

## 3. 阶段三：流式交互与优化 (Day 4-5)
- [ ] **流式播放优化 (关键体验)**
    - [ ] 实现 **Audio Queue (音频队列)**：解决网络抖动导致的语音卡顿，确保句子间平滑过渡。
    - [ ] 优化首字延迟：后端采用流式输出，一生成完一句立刻进行 TTS 合成。
- [ ] **UI/UX 交互打磨**
    - [ ] 实现“按住说话”交互效果 (仿物理按钮)。
    - [ ] 添加声波纹动画 (用户说话时/AI 说话时)。
    - [ ] 添加背景白噪音 (雨声/篝火) 播放器，支持音量独立调节。

## 4. 阶段四：验证与交付 (Day 6)
- [ ] **真机调试**：在手机浏览器上测试，验证锁屏播放和麦克风权限。
- [ ] **Prompt 调优**：调整 System Prompt，确保生成内容适合睡前场景（助眠、深度、非刺激性）。
- [ ] **代码整理**：整理项目结构，补充 README。

## 5. 待确认事项

- [ ] TTS 方案：默认使用 Edge TTS (免费) 还是 Azure TTS (更自然)？
