# 🌙 Sleep-Lamp - AI 睡眠情绪疏导助手

一个结合心理学专业知识的 AI 睡眠辅助应用，通过自然对话帮助用户缓解情绪压力、改善睡眠质量。

## ✨ 核心特性

### 🧠 专业心理学支持
- **情绪识别**: 自动识别用户情绪状态（焦虑、委屈、懊悔、伤心等）
- **专业话术**: 基于心理学教授提供的人本主义流派理论
- **情绪疏导**: 深度情绪疏导，突破传统6轮限制
- **无条件关注**: 采用人本主义流派的无条件积极关注原则

### 🎧 智能语音交互
- **实时ASR**: 语音转文字，自然对话体验
- **流畅TTS**: 文字转语音，温暖声音陪伴
- **音色一致**: 保持用户选择的音色，无意外切换
- **流式处理**: 实时响应，低延迟体验

### 🎯 个性化体验
- **情绪感知**: 智能识别并响应用户情绪状态
- **故事定制**: 根据情绪状态生成合适的故事
- **专业疏导**: 针对不同情绪提供专业安抚话术
- **深度陪伴**: 提供安全、温暖的对话空间

## 🛠️ 技术架构

### 前端 (React + Vite)
- 实时 WebSocket 通信
- 语音录制与播放
- 响应式用户界面
- 智能唤醒词检测

### 后端 (Node.js + Express)
- AI 对话管理
- 情绪识别与处理
- TTS/ASR 服务集成
- 心理学技能系统

### AI 集成
- 通义千问大模型
- DashScope TTS 服务
- 专业心理学话术库
- 流式响应生成

## 🚀 快速开始

### 环境要求
- Node.js 18+
- Python 3.11+
- 阿里云 DashScope API 密钥

### 安装步骤
1. 克隆项目
2. 安装依赖：`npm install`
3. 配置环境变量（API密钥等）
4. 启动服务：`npm start`
